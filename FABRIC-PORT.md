# Unofficial Fabric 26.2 port

This branch adapts [IntellectualSites/FastAsyncWorldEdit](https://github.com/IntellectualSites/FastAsyncWorldEdit)
for the BRBW map editor's Minecraft 26.2 Fabric server. It is not an official
IntellectualSites or EngineHub release. The Fabric platform implementation was
adapted from [nekogabriel-bit/FastAsyncWorldEdit-Fabric-community](https://github.com/nekogabriel-bit/FastAsyncWorldEdit-Fabric-community)
at `8fad6fb7c5cbf5aa47094bb0564e5c875cc81f56`, then applied to upstream
commit `944c416b0a7cc735a08c11201d348ea61b80c368`.

The Fabric distribution is server-only. Clients use the server's WorldEdit
commands and do not install this JAR. The source and binary remain under
GPL-3.0-or-later; retain the upstream copyright, license, and notices when
redistributing modified builds.
